# 26fit • Central Comercial

Aplicação interna de planejamento, execução e avaliação de campanhas comerciais da rede 26fit.

O primeiro deploy contém uma interface de demonstração com dados fictícios. **Não utilize dados reais até autenticação, permissões e base compartilhada estarem habilitadas.**

Stack: Next.js (App Router), React, Vercel. Projeto conectado ao GitHub `AlissonMeesPersonal/centralcomercial` (branch `main`).
